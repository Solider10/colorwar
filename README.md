# 🎨 حرب الألوان — Color War

لعبة استراتيجية بسيطة وسريعة: لوّن الخريطة، اخطف مربعات خصمك، واستخدم الكروت الخاصة عشان تكسب.
A quick, simple strategy game: paint the map, steal your rival's tiles, and win with power cards.

▶️ **العب الآن / Play now:** https://solider10.github.io/colorwar/
🔒 **سياسة الخصوصية / Privacy:** https://solider10.github.io/colorwar/privacy.html

---

## ✨ المميزات الحالية (الإصدار 1.0) / Features
- 🤖 اللعب ضد الكمبيوتر بـ ٣ مستويات (سهل، متوسط، صعب) / vs Computer, 3 levels
- 👥 اللعب ضد صديق / Play with a friend
- 🗺️ خرائط 5×5 و7×7 و9×9 / 3 board sizes
- 🎴 ٦ كروت خاصة بتكسبها أثناء اللعب: قنبلة، قفزة، دور تاني، درع، موجة، قناص / 6 power cards: Bomb, Jump, Extra Turn, Shield, Wave, Sniper
- 🎨 ٦ ثيمات ألوان منها ثيم ليلي نيون / 6 color themes incl. Neon Night
- 🌐 عربي وإنجليزي / Arabic & English
- 🏆 عداد نقاط وقائمة تقييم محلية / Score counter and local leaderboard
- 📴 بتشتغل بدون إنترنت، وبدون إعلانات، وبدون جمع بيانات / Works offline, no ads, no data collection
